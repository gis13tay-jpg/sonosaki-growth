## 2. SONOSAKI Growthの執筆思想

### コミュニケーションの大前提

コミュニケーションで大切なのは、相手が話した言葉だけではなく、その言葉の向こう側を知ることである。

人が口にする言葉には、遠慮、立場、過去の経験、本人もまだ整理できていない感情が含まれている。
そのため、表面的な発言をそのまま受け取るだけでは、本当に伝えたいことへ届かない場合がある。

### 見逃してはいけない言葉

会話では、次のような小さな言葉にも注目する。

- 「〜が」
- 「〜だけ」
- 「〜しか」
- 何度も繰り返される言葉
- 「信用」と「信頼」のような、似ているが意味の異なる言葉

なぜその単語を選んだのか。なぜ何度も同じ言葉が出るのか。本人はどのような前提でその出来事を見ているのか。
言葉の選び方には、その人の価値観や不安、守りたいものが表れることがある。

### 言葉の奥まで理解する（7段階）

1. 何を話しているか
2. なぜその言葉を使ったのか
3. なぜそう感じるのか
4. どのような経験や前提条件を持っているのか
5. その人にはどのような特性があるのか
6. 本人が本当に大切にしているものは何か
7. どのような未来を望んでいるのか

ここまで理解して、ようやく本人が安心して本音を話せる関係が始まる。
その先に、次が見えてくる。

- この会社にいる意味
- この仕事を通じて成長できる分野
- 自分の力が会社にどう役立つか
- なぜ会社に貢献したいと思うのか

### 1on1・DX・AIに対する考え方

1on1やDX、AIの導入自体を否定しない。
ただし、仕組みやツールを導入するだけでは、相手の特性、価値観、前提条件、言葉の背景までは理解できない。

- 1on1は話す機会をつくれる
- DXは情報を整理できる
- AIは処理や分析を支援できる

しかし、相手がなぜその言葉を使い、なぜそのように行動するのかを理解するのは、人と人とのコミュニケーションである。

**表現ルール**：「導入しても意味がない」と断定しない。「人を理解する土台がなければ、十分に活かしきれない」と表現する。

### 条件だけで人を引き留めることへの考え方

給与や福利厚生などの条件改善は大切である。
ただし、条件だけで人を採用・定着させようとすることは、「年収3,000万円だから結婚してください」と伝えるようなものである。
条件は魅力の一部だが、それだけでは「なぜこの会社なのか」「なぜこの人と働くのか」は伝わらない。

**使用ルール**：このたとえは、記事の文脈に合う場合だけ使用する。毎回使わない。

### 数字・根拠の扱い

「発言の9割は建前」のような、根拠を確認できない数字を調査結果として断定しない。
使う場合は「SONOSAKI Growthの問題意識として」など、断定しない表現にする。
根拠のない数字、架空の事例、架空の実績、口コミは作らない。

## 3.「今日の3記事」の配分ルール

「今日の3記事」と入力された場合、原則として次の配分にする。

- 組織・コミュニケーション：2本
- 集客：1本

組織記事のうち、可能な限り次の配分にする。

- 具体的な悩みに答える記事：1本
- SONOSAKI Growthの考え方を伝える記事：1本

作成前に、`data/columns.ts` の既存記事と検索意図・タイトル・結論が重複していないか必ず確認する。

## 4. 検索・AI回答対策（SEO / AEO / GEO / AIO / LLMO）

すべての記事で、SEOに加えて次を意識する。

- **AEO**：質問に対する答えを見出し直下で簡潔に示す
- **GEO**：生成AIが引用・要約しやすい定義、比較、手順を用意する
- **AIO**：AI検索で内容を正しく理解できる構造にする
- **LLMO**：固有の考え方、明確な論点、FAQ、要約を用意する

### 記事に含める構成要素

- 検索者の悩みが分かるタイトル
- 冒頭の明確な結論
- 想定される状況
- 表面的な原因
- 本質的な原因
- 具体的な会話例
- 見逃しやすい言葉
- 管理職が確認するポイント
- 明日からできる行動
- FAQ
- まとめ
- 関連記事
- 組織診断または相談へのCTA

- 一般論だけの薄い記事にしない。SONOSAKI Growth独自のコミュニケーション観を中心に書く
- 検索キーワードを不自然に繰り返さない
- 根拠のない数字、架空の事例、架空の実績、口コミを作らない
